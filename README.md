# Proyecto RPG Biopunk Soviético (GDD & Código)

Documento de Diseño de Juego (GDD) y repositorio de desarrollo para un **Action RPG 2D Isométrico** en Pixel Art con combate en tiempo real, ambientado en una ciudad soviética abandonada invadida por biomasa y niebla.

## Cómo Visualizar este Proyecto
1. **En GitHub:** Puedes subir este repositorio a tu cuenta de GitHub para leer y editar las notas desde cualquier navegador o móvil.
2. **En Obsidian:** Abre la carpeta del proyecto como una bóveda (Vault) para navegar por enlaces interactivos y el grafo de lore.
3. **Con el Asistente:** Puedo modificar, expandir o crear nuevas secciones directamente cuando me lo indiques.
